BREAKING (Go API, source-level) - verified against git diff of non-test code

Earlier drafts stated “no breaking changes”; that is NOT correct. The following exported signatures changed since helixcode-v1.1.0:

  • serviceregistry.(*ServiceRegistry).Unregister(name) and UpdateHealth(name, healthy) now return error (a551ffd, persistence errors are surfaced).
  • emulator.Cleanup(ctx) is now Cleanup(ctx, avdName string) and cuttlefish.Cleanup(ctx) is now Cleanup(ctx, ownerToken string) (552be2c, process kill is scoped to OUR device; the host-wide reap fallbacks were removed). cmd/emulator-cleanup was updated accordingly.
  • Behaviour change: cuttlefish default NetworkHost=true and image refs are passed after -- (fbff142). health.CheckHTTP treats 4xx as UNHEALTHY and accepts only 2xx-3xx (d21f0d8). envconfig now surfaces SET-but-invalid env values as errors instead of silently defaulting (90cb2f9).

Callers of the changed signatures must be updated; this is why the proposed version is a minor bump on a 1.x line only if the maintainers accept the signature changes (decision pending).
